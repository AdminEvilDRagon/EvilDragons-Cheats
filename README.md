## ⚡ Quick start

1. Pick your game from the table above and open its folder.
2. Follow the install steps in that game's README (usually: install the mod loader, drop one DLL into `plugins`).
3. Start the game and press **F1**.

## ✨ What every menu has

- 🎨 **Themes** – Dragon, Neon, Inferno, Ocean, Purple, Gold
- ⌨️ **Rebindable hotkeys** – use the important cheats without opening the menu
- 💾 **Save Settings** – your toggles are active again on the next start
- 🧹 **Clean & safe** – nothing is changed until you switch it on, all game files stay untouched

## 📁 Repository layout

```
EvilDragons-Cheats/
├── assets/                 logo & shared images
└── games/
    └── CanEmAll/
        ├── README.md       features, install, hotkeys
        └── src/            plugin source (C#)
```

**Adding a new game:** create `games/<GameName>/` with its own `README.md` and `src/`, then add a row to the table above.
